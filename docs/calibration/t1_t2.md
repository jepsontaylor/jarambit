# T1 -> T2 calibration and RS-karambit-v2 human-max / fatigue (PR-0.31.3)

T1 = search tier (`qd::evaluate`: plate FEM at search area 2.0 mm², search-mesh bias). T2 = certification (`fem::certify`: min over 0.25 / 0.125 mm², no bias).
Designs: the first 40 `bench/fixed_1k` genomes at stride 12 that evaluate in both tiers (`jarambit calib-t1t2 --n 40 --stride 12`; 40 of 80 sampled; illegal genomes have no T1 FEM).
Data: `t1_t2.csv`; summary `t1_t2.json` (`python3 ops/calibration/t1_t2.py`, CI `--check`). Bar: residual sigma <= 7 % per case.

| case | factor T2/T1 (median) | residual sigma | max abs residual | sigma <= 7 % |
|---|---|---|---|---|
| lateral (lat_rob) | 0.947 | 6.5 % | 17.1 % | yes |
| ring pull (ring_rob) | 1.059 | 5.5 % | 17.2 % | yes |
| in-plane tip (pry20) | 0.925 | 3.3 % | 8.4 % | yes |
| chord twist (twist_joint) | 0.865 | **10.8 %** | 39.1 % | **no** |

Twist does not meet the 7 % bar: a log-linear fit in T1 only brings it to 8.2 %. The twist peak sits near the tip and its St-Venant 3D factor depends on the
local section, which the search mesh resolves poorly. This matches the Wave27.1 finding that the search-level tip estimate is optimistic. Policy until fixed:
twist is gated only on T2 (certification), never on a calibrated T1 value; search uses T1 x 0.865 with a margin of >= 1.25.

## RS-karambit-v2 human-max structural cases (T2, first yield, joint thin+hot, 828 MPa)

| case | load | SF min / median / max (40 designs) | pass |
|---|---|---|---|
| twist about chord | 16.2 N·m | 0.045 / 0.060 / 0.075 | 0 / 40 |
| tip in-plane (worst of normal/axial) | 1000 N | 0.42 / 0.59 / 0.69 | 0 / 40 |
| spine, distributed, toward edge | 3427 N | 0.30 / 0.45 / 0.50 | 0 / 40 |
| ring-back impact, static equivalent (L6, DAF 2 x 1500 N) | 3000 N | 1.49 / 2.01 / 2.12 | 40 / 40 |
| L7 fatigue, lateral 0..180 N, Marin + Goodman | Se ≈ 270 MPa | 0.61 / 0.72 / 0.81 | 0 / 40 |
| ring finger-bearing width (bore length) | >= 10 mm | 4.5 / 4.9 / 5.3 mm | 0 / 40 |
| ring bore edge radius | >= 1.5 mm | export spec; feasible (bearing >= 2r + 1 mm) on all | — |

Reading: on the current crescent genotype (plate t ≈ 4.5–6 mm, 70–80 g) the human-max twist needs about 17x the capacity, tip in-plane and spine about 2x,
and fatigue about 1.4x. The 10 mm finger-bearing width needs a ring flare/bolster that the genotype cannot express. Meeting `human_max` therefore needs
new genotype features (ring bolster, thicker spine/tip rail) and probably relaxing the soft mass target. These are inputs to v0.33 (new genotypes). The search
fitness is unchanged in v0.31: RS-v2 is published and evaluated (`fem::rs_v2_human_max_pass`, `rs_v2_fatigue_pass`) but does not yet gate search.
