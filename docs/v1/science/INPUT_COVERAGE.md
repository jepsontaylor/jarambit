## Reconciliation decisions

**Keep:** provenance, fail-closed reporting, explicit numerical validity, correct material/process identity, held-out physical validation, uncertainty decomposition, sham/aged/worn controls, inspection capability, inert handling evaluation, and honest probability/mass accounting.

**Modify:** consolidate overlapping proposals into one evidence contract; distinguish fit admissibility from demonstrated asymptotic convergence; retain orthogonal statuses rather than one qualification ladder; integrate with current Rust engine and report generators; bind local/native CAD separately; preserve missing-data meaning and historical records.

**Defer:** actual laboratory execution, acquisition of supplier/process evidence, coating/chemistry research, learned aesthetic preferences, GPU/distributed work and new representations until prerequisites and scope are established. Ready protocols/import tools can be implemented earlier. No delay is imposed on fixing demonstrated software defects.

**Reject as proof:** a scalar SF as survival probability; marginal p05 values as joint success; mesh/cross-code agreement as physical validation; a small pristine coating dataset as broad qualification; alloy name as material-state identity; a renderer's thickness/color as metrology; many runs sharing assumptions as independent physical evidence; negative search results as a global impossibility theorem.
